# Reference benchmark routes

Companion profile: `reference-profile.json` records the observed Apple M4 Pro / 48 GB / Chromium 150 / ANGLE Metal environment. Performance target is 1920x1080 at DPR 1, 60 FPS, p95 frame interval <=17.5 ms and p99 <=25 ms. UI comparison captures use the source scene dimensions, excluding the editorial footer. These are targets and a measurement protocol, not results.

## Procedure and truthfulness

- Pin build, source, content, asset and settings revisions; record seed and checkpoint/history fixture identity.
- A performance fixture may begin at an authored checkpoint. It is not proof of campaign reachability, a new-player run or 8–12h duration. Those require separate normal-input playthrough evidence.
- Separate cold asset loading from warm gameplay capture. Record network conditions and actual transferred/decoded payload sizes; do not report renderer object counts as exact GPU memory bytes.
- Record frame interval distributions plus CPU simulation/animation/render and available GPU timing separately. Keep failed/unevaluated GPU queries explicit.
- Perform equivalent normal and reduced-effects captures. Lower cosmetic quality may not remove required telegraphs, shadow/contact cues or companion meaning.
- Enemy cap counts the boss inside total hostiles. Two large fully simulated creatures is a global encounter cap, not a per-system allowance. Crowd representation has its own measured cost.
- Keep before/after resource traces and screenshot/video evidence. A single still image or successful build is not a performance/readability result.
- Browser/OS/hardware other than the recorded profile, physical gamepad behavior and newcomer pacing remain unverified until actually exercised.
